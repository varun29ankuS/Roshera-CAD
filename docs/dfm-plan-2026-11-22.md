# DFM comprehensive plan (agent worktree, 2026-11-22)

Doctrine unchanged: exact-or-refuse; every verdict names faces + measured + limit; every
threshold is a PackParams field with a default whose RuleProvenance says honestly what it
is. No edition/clause from memory: every CNC/sheet/casting number below is vendor or shop
practice -> `ShopPractice` (named as such), never dressed as a Standard.

## Shared analyzers (new)
- `analyzers/corners.rs` `concave_corners(model, solid)` — every AAG arc labelled
  Concave (sharp inside edge) with its edge curve (Line direction / circular rim) and the
  two faces' analytic geometry; every `Undetermined` arc is a typed refusal (never
  silently dropped — `blend_radius`'s sharp arm skips classify_edge errors, this one
  does not). Concave cylindrical/toroidal blends come from `blend_radius` (reused).
- `analyzers/holes.rs` `hole_census(model, solid)` — `drawing::hole_features::
  recognize_hole_stacks` (reused verbatim: THRU by topology, drill-point vs flat floor,
  counterbore/countersink) + full drilled length from AAG station ranges; every
  `bore_face_ids` wall NOT claimed by a stack is reported as an unrecognised bore with
  its own (lower-bound) wall length — rules decide on it only where a lower bound is
  enough to prove a violation, otherwise Unverifiable.
- `analyzers/revolution.rs` `axisymmetry(model, solid, axis)` — per-face: coaxial
  surface of revolution / plane perpendicular with circular coaxial trims = turnable;
  otherwise named off-axis face; freeform = refusal.
- `analyzers/sheet.rs` `sheet_features(model, solid)` — bends = tangent-joined coaxial
  cylinder pairs (concave inner r, convex outer r+t, partial sweep); flanges = planar
  faces; hole rims on flanges; exact point-to-segment distances from a hole rim to the
  flange's Line boundary edges, split into bend-tangent edges vs free edges.
- `thickness.rs` extension: CONGRUENT opposing planar faces (identical projected loop
  geometry incl. inner loops: an extrusion's top/bottom, a sheet's two skins) prove
  overlap exactly — the case every real plate/sheet hit as "unverifiable" before.

## CNC milling pack `cnc_3_axis` (params: setup_directions [+Z,-Z], min_tool_diameter 3.0,
## max_corner_reach_ratio 4.0, max_drill_depth_ratio 10.0, min_drill_diameter 1.0,
## max_drill_diameter 13.0 (drill-series scope), drill_series metric_0_1,
## allow_flat_bottom_holes false, min_wall 0.8)
| id | measures | analyzer | default / source |
|---|---|---|---|
| cnc.internal_corner_radius | inside corner radius where a rotating cutter's SIDE forms it (edge/fillet axis parallel to a setup dir, both faces walls); sharp = 0 | corners + blend_radius | >= min_tool_diameter/2; ShopPractice (tool radius bound) |
| cnc.corner_reach | vertical fillet axial length / (2r) = reach L:D of the tool that finishes it | blend_radius + AAG station | <= 4.0; ShopPractice (end-mill length of cut ~3-4xD) |
| cnc.hole_depth_ratio | drilled length / drill dia per recognised stack (+ lower bound for unrecognised bores) | holes | <= 10; ShopPractice (twist drill; deeper = gun drilling) |
| cnc.min_hole_diameter | drill dia | holes | >= 1.0 mm; ShopPractice |
| cnc.standard_drill_size | drill dia vs metric 0.1 mm jobber series (<= 13 mm scope; bigger = interpolated) | holes | ShopPractice (commercial drill series) |
| cnc.blind_hole_floor | blind floor: drill-point included angle (flat = 180) vs standard points 118/135/140 | holes | ShopPractice |
| cnc.hole_access | each hole's entry direction (THRU: either end) vs setup_directions | holes | geometric necessity (tool enters along the hole axis); ShopPractice for the setup plan |
| cnc.min_wall | pair thickness | pair_thickness | >= 0.8 mm; ShopPractice (common CNC guide metal figure) |

| sheet.bend_radius | inner bend radius; sharp concave edge = 0 | sheet + corners | >= 1.0 t; ShopPractice (0.5t soft .. 1.5t hard) |

## Casting pack `casting` (params: pull_direction, min_draft_deg 1.0, min_wall 1.0,

| cast.min_wall / cast.max_wall | pair thickness band (thin = misrun, thick = hot spot/porosity) | pair_thickness | ShopPractice |

## Molding extension (no new params)
- mold.side_action (bores not parallel to pull), mold.trapped_core (internal_voids),
  mold.sharp_internal_corner (radius-0 concave edges).

## Entry point + wiring
- `dfm::analyze(model, solid, params)` enumerates the solid's faces itself; REST
  `POST /api/agent/parts/{id}/dfm` calls it (body = PackParams verbatim, new variants
  automatically reachable); MCP `dfm_check` enum + body + KB tables updated; api-server
  router test per new pack (disconnection gate).

## State of the art (checked 2026-11-22, WebSearch; vendor figures = ShopPractice)

Standards status checked (publisher / national-body listings):
- ISO 2768-2:1989 is CANCELLED, replaced by **ISO 22081:2021** (general geometrical and size
  specifications; iso.org lists it reviewed/confirmed 2026) — https://www.iso.org/standard/72514.html.
  Any in-tree reference to ISO 2768-2 for geometric general tolerances is out of date (the MCP KB's
  `general_tolerance` reference cites ISO 2768 — flagged for the KB owner, not changed here).
- ISO 8062-3 current edition is **2023 (Ed. 2)**; 2007 withdrawn — https://www.iso.org/standard/77952.html.
- ISO/ASTM 52910 current **2018 (Ed. 1)**; scope excludes process/material-specific data.
- DIN 6935 current **2011-10** (+ Beiblatt 1/2 2011-10); DIN 338 current **2006-11**.
- ISO 10135 current **2007**, confirmed 2022 — drawing indications only.
- NADCA Product Specification Standards: 11th ed. 2021 confirmed (https://www.diecasting.org/standards);
  yearly revisions, so a newer printing may exist — not consulted for values.

Gaps competitors run that we don't (named, not hidden): sheet hole-to-hole spacing, hole Ø ≥ t,
notch/relief rules, K-factor flat pattern; general visibility-based undercut for moulding/casting
and CNC (non-hole faces); thin-rib width (void-side pairing); turning inside-corner nose radius;
threads (cosmetic in the kernel). Where we are AHEAD: every verdict is exact-or-refuse with typed
refusals and threshold provenance; findings are certified against the live B-Rep, not a mesh.

## Animations (founder ask)
`dfm/animation.rs` `animate_report(model, solid, report)` → one `DfmAnimation` per violation,
built from the verdict's measured/limit/witnesses (tool Ø = limit, plunge = drilled length,
caliper gap = measured). Kinds: tool_approach, drill_plunge, setup_cycle, mold_separation,
layer_build, caliper, spindle_spin, highlight (fallback). REST adds `animations`; the app's
`DfmAnimationPlayer` plays them over the part.

## Fixtures (kernel ops)
box − box pocket (sharp vertical corners) vs pocket with filleted vertical edges; deep
narrow blind hole vs shallow; Ø6.35 vs Ø6.6; flat vs 118° floor; side hole vs top hole;
turned shaft with/without cross hole; L-bracket sheet with/without hole near bend.
